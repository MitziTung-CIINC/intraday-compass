# 真实行情回放

在监测列表选择股票，打开「行情配置 → 历史演练」，关闭配置窗口后选择「今日回放」或「前一交易日」。

- **今日回放**：按北京时间选择当天。盘中只载入已结束的分钟K线；收盘后点击「重新载入真实行情」可重新检查全天数据。
- **前一交易日**：从行情源实际返回的指数交易日期中选择今天之前最近的一天。不直接把日历上的昨天当作交易日。
- 点击「开始历史演练」逐分钟播放，支持暂停、1/5/20倍速；播放完毕再次点击开始可从头回放。
- 日期、根数、数据截止时间及分钟覆盖情况均在回放工具栏展示。暂停时保留当前位置的指标供复盘，不触发新的成熟信号通知。

## 数据边界

数据来自东方财富公开分钟行情接口，不需要个人 API Key。接口可能限制历史天数或暂时不可用；所选日期无数据时明确报错，不换成其他日期，不补造K线。

「全天分钟覆盖完整」表示09:31—11:30及13:01—15:00共240个连续交易分钟均有数据；接口可能额外提供09:30记录，共241根。这个标识不代表供应商数据经过交易所独立认证。

有缺口的行情只显示实际返回的K线，并提示缺失分钟数。指数时间未对齐、日K不足或其他模型硬门槛未通过时，不生成成熟B/S交易判断。日K仅使用回放日期之前的数据，避免在开盘回放时提前使用当天收盘信息。

回放不是自动成交回测，不代表实际可成交价格或收益；不会改写真实成交台账，也不会把回放价格保存为持仓最新行情。底仓与可卖数量仍由使用者手工设置，零持仓不会被虚构成可做T底仓。

## 本地与部署接口

网页请求 `/quote?symbol=000938&market=SZ&session=today`；`session=previous` 保留前一交易日功能。服务器转发至行情桥的 `/history`，本地预览也支持 `/quote` 的相同参数。

返回 `meta.realHistorical`、`meta.quoteSource`、`meta.session`、`data.tradeDate`、`data.coverage` 和真实 `minuteBars`。部署时应同时更新网页与行情桥（包括 `tools/history-session.mjs`），否则新页面不会接受缺少完整性信息的旧接口响应。
