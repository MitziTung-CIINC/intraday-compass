# 接入东方财富、同花顺或券商 L2 实时行情

可以接入，但前提是你已经从数据提供方取得**明确允许程序调用的 API、SDK 或行情网关权限**。普通桌面端或手机端的 L2 会员通常只代表客户端展示权限，不自动包含 API 调用、模型计算、非展示使用或再分发授权。

本项目只读取行情并生成研究提示，不连接券商委托接口。请勿通过抓包、破解、注入、读取客户端内存或共享会员账号来获取行情。

## 先判断你拥有哪一种权限

| 你目前拥有的服务 | 能否直接接入 | 建议 |
|---|---:|---|
| 东方财富/同花顺桌面或手机 L2 会员 | 通常不能 | 向提供方确认是否另有正式 API/SDK 产品及非展示使用授权 |
| 东方财富 Choice 等正式量化数据接口 | 可以 | 按合同和接口文档接入，优先使用本地适配器 |
| 同花顺数据接口的 HTTP API 或 SDK | 可以 | 使用官方 Token/SDK，经本地适配器转换字段 |
| 券商提供的独立行情 API/SDK | 可以 | 确认接口含 L2 行情、允许本地模型使用，并遵守并发和频率限制 |
| 只有交易账号和客户端登录密码 | 不可以 | 不要把账号密码填入分时罗盘，也不要尝试绕过客户端 |

在开始前向服务商确认四件事：

1. 权限包含的是 Level-1、Level-2、逐笔成交、逐笔委托还是仅快照；
2. 是否允许用于本地模型计算，也就是“非展示使用”；
3. 是否允许保存分钟 K 线、历史回放，以及可以保存多久；
4. 是否禁止转发给其他用户。公开发布本项目时，不能把你的密钥或付费行情一起发布。

交易所 Level-2 行情属于授权数据产品，展示和非展示使用可能采用不同许可。可参考[上证所 Level-2 行情说明](https://www.sseinfo.com/services/assortment/level2/)；具体权限以你的数据服务合同为准。

## 两种接入方式

### 方式 A：在页面中直接配置 REST 或 WebSocket

适合：提供方允许浏览器跨域访问，认证方式为 Bearer Token，返回字段简单，并且你只需要更新最新价。

进入“行情配置”后：

1. 选择 `REST轮询` 或 `WebSocket`；
2. 填写接口地址，可使用 `{symbol}` 和 `{market}` 占位符；
3. 将临时 Token 填入“临时访问令牌”；
4. 按接口响应填写价格、昨收、成交量、源时间、指数和板块字段路径；
5. 保存后核对页面上的源时间、接收时间和陈旧状态。

直接 REST 接入的限制：

- 当前页面只会以 `Authorization: Bearer <token>` 发送凭证；需要自定义签名、POST 请求、证书或多个请求头时不能直接接入；
- REST 最短轮询间隔为 1 秒；
- 只返回最新价而没有分钟 K、日 K、指数/板块序列和 `meta.validation` 时，页面可以显示价格，但会冻结完整 B/S 判断；
- 直接 WebSocket 适合推送最新价，当前不承担完整分钟结构和日线校验。

因此，完整模型建议使用方式 B。

### 方式 B：使用本地行情适配器（推荐）

适合：官方 SDK、HTTP 签名接口、WebSocket 逐笔数据、需要多接口合并或希望密钥不进入浏览器。

```text
东方财富 / 同花顺 / 券商官方 API 或 SDK
                 ↓
        本地行情适配器（你控制）
        - 保管 Token 和签名密钥
        - 统一证券代码和时间
        - 合成 1 分钟 K 线
        - 合并日 K、指数和行业板块
        - 执行数据校验
                 ↓
http://127.0.0.1:8770/quote?symbol={symbol}&market={market}
                 ↓
              分时罗盘
```

推荐让适配器只监听 `127.0.0.1`，并只允许 `http://localhost:4173` 跨域访问。密钥放在适配器进程的环境变量中，不要写入前端代码、README、截图或 Git 仓库。

### 必须正确映射的字段

| 罗盘字段 | 含义 | 常见错误 |
|---|---|---|
| `data.price` | 最新成交价或服务商定义的最新价 | 把买一价误作最新价 |
| `data.previousClose` | 昨日收盘价 | 复权价和未复权实时价混用 |
| `data.volume` | 当日累计成交量 | 手、股、张的单位混用 |
| `data.time` | 数据源时间 | 用本机接收时间冒充源时间 |
| `minuteBars` | 当前交易日 1 分钟 OHLCV | 重复累计成交量，或把未完成分钟当成已完成分钟 |
| `dailyBars` | 至少 20 根多日日 K | 日期不是 `YYYYMMDD`，或复权口径不一致 |
| `sectorChange` | 真实行业/板块同期涨跌幅 | 用大盘指数涨跌幅冒充行业板块 |
| `indexChange` | 匹配市场指数同期涨跌幅 | 用当前快照复制到所有历史分钟 |
| `meta.validation` | 适配器校验结果 | 无校验却固定返回 `passed: true` |

股票代码需要统一成六位代码，并正确传递 `SH`、`SZ` 或 `BJ` 市场。所有源时间建议使用带 `+08:00` 时区的 ISO 8601 格式。

## 适配器应执行的校验

只有全部关键条件通过时才返回 `meta.validation.passed: true`：

1. 最新价、昨收和源时间有效，源时间不在未来；
2. 最新价没有超过你在页面中设置的陈旧阈值；
3. 个股/ETF、匹配市场指数和日 K 数据齐全；
4. 最近一分钟 K 没有过期；
5. 最新价与最近一分钟收盘价的偏差处于合理范围；
6. 指数和行业数据按“同一时间或不晚于个股分钟”的规则对齐；
7. 成交量单位、复权口径和证券市场映射一致。

项目默认免费行情桥使用的参考阈值是：最新价不超过 15 秒、分钟 K 不超过 90 秒、快照与最近分钟收盘价偏差不超过 1%。付费 L2 接口不应机械照搬这些数值，应按服务商时间戳、推送频率和交易时段实测后设置；校验失败时应冻结信号，而不是为了消除警告而放宽阈值。

## 不同服务商的建议流程

### 东方财富

1. 先确认你购买的是客户端 L2 会员，还是带正式调用文档和密钥的量化数据接口；
2. 如需程序调用，向官方咨询 Choice 量化接口或其他被明确授权的数据服务；
3. 根据合同确认是否包含实时、逐笔和非展示使用；
4. 在本地适配器中调用官方接口并转换成上述数据契约；
5. 不要把个人东方财富账号、客户端 Cookie 或 API Key 提交到仓库。

东方财富的客户端 L2 产品和量化接口是不同的产品形态，可分别参考[东方财富 Level-2 产品页](https://emdesk.eastmoney.com/PC_Activity/ShoppingCart/Index)与[Choice 量化接口说明](https://choice.eastmoney.com/FileDownload/CFTG201208.pdf)。

### 同花顺

1. 使用同花顺正式“数据接口”产品，而不是直接复用普通客户端会员登录；
2. 按官方流程申请账号、访问令牌和对应行情权限；
3. 根据场景选择 HTTP API、Python/C++/Java/C# SDK 或官方支持的连接方式；
4. 让本地适配器负责 Token 刷新、签名、重连、限流和字段转换；
5. 上线前验证源时间、推送中断后的重连和休市状态。

官方入口见[同花顺数据接口](https://quantapi.5ifind.cn/gwstatic/static/ds_web/quantapi-web/)和[接口使用流程](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/help-center/deploy.html)。

### 券商行情 API

1. 向券商确认行情接口和交易接口是否分开授权；
2. 只申请只读行情权限，不在本项目中启用委托权限；
3. 确认支持的证券范围、行情级别、快照/逐笔字段、限流和交易时段；
4. 将券商专用代码、时间戳和成交量单位转换为罗盘标准格式；
5. 在适配器中隔离交易凭证，最好使用独立只读 Token。

## 页面配置示例

适配器在本机 `8770` 端口提供标准 REST 响应后，在分时罗盘中填写：

```text
模式：REST轮询
行情提供方名称：我的持牌 L2 适配器
行情时效声明：接口授权为实时行情
接口地址：http://127.0.0.1:8770/quote?symbol={symbol}&market={market}
轮询间隔：1000 毫秒
陈旧阈值：按接口实测设置，建议先保持 15 秒
价格字段路径：data.price
昨收字段路径：data.previousClose
成交量字段路径：data.volume
时间字段路径：data.time
板块字段路径：data.sectorChange
指数涨跌路径：data.indexChange
指数点位路径：data.indexLevel
```

如果 Token 只在适配器中使用，页面“临时访问令牌”留空。

## 上线前验收清单

- [ ] 服务商合同或控制台明确显示 API/SDK 和实时行情权限；
- [ ] 密钥只存在本机环境变量或安全密钥存储中；
- [ ] 适配器只监听本机地址，CORS 仅允许分时罗盘；
- [ ] 盘中连续观察至少 30 分钟，没有时间倒退、重复分钟或累计量突变；
- [ ] 与服务商官方客户端抽样核对最新价、昨收和成交量单位；
- [ ] 断网、Token 过期和服务商限流时，`meta.validation.passed` 会变为 `false`；
- [ ] 收盘、午休和非交易日不会把历史数据误标为实时；
- [ ] 没有在 Git、截图、日志或浏览器持久存储中泄露密钥；
- [ ] B/S 提示仍由人工判断和执行，系统不会发送委托。

## 常见问题

**为什么填了 L2 会员账号仍然连不上？** 会员账号通常只用于官方客户端，页面不会也不应该用它登录或抓取客户端。你需要独立的 API/SDK 权限。

**L2 一定比免费接口更适合分时罗盘吗？** L2 能改善最新价、盘口和逐笔数据的时效，但当前核心成熟度模型仍依赖 1/5/15 分钟结构、日 K、指数和板块上下文。只替换最新价不能自动提升信号质量。

**能否把付费数据一起分享给其他测试者？** 通常不能。请让每位用户自行申请数据权限，并在本机配置自己的适配器和 Token；是否允许再分发必须以服务商合同为准。

**接口故障时怎么办？** 返回 `meta.validation.passed: false` 并保留失败原因，页面应冻结 B/S。可以降级回项目自带的免费行情桥，但必须明确显示数据源已经变化。
