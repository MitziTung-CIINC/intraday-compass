# 分时罗盘

**给普通持仓用户用的 A 股 / 场内 ETF 日内盯盘与做 T 复盘工具。**

输入股票名称、6 位代码、持仓数量和成本，就可以在一个页面里查看分时走势、B/S 信号成熟度、持仓状态，并记录自己真实完成的买卖操作。

> 分时罗盘是只读研究工具：不会连接券商账户，不会读取资金，也不会替你下单。页面信号不构成投资建议，公开行情不能替代券商终端。

## 为什么做这个项目？

这个项目起因很简单：当一只股票持仓成本较高时，很多人会考虑利用日内波动做 T，慢慢降低持仓成本。但真正操作时，经常遇到这些问题：

- 分时图、均价线、成交量和指数散落在不同页面，来回切换容易错过重点；
- 看到急涨就想卖、看到急跌就想买，很容易被情绪带着走；
- 买卖完成后没有认真记录，过几天已经说不清这次做 T 到底有没有成功；
- 只看单一指标，容易把下跌中继误认为买点，或者过早卖掉仍在走强的持仓。

分时罗盘把一套日内 T0 课程中的趋势、均价线、量能阶段、九转和指数环境等方法整理成可观察、可记录、可复盘的流程。它不追求“预测每一次涨跌”，而是希望帮助用户在真实交易前多看一眼条件、在交易后留下完整记录。

## 它想解决什么问题？

项目目前围绕四个目标设计：

1. **看得明白**：把价格、均价线、成交量、指数环境和信号成熟度集中在同一页面。
2. **少凭感觉**：先判断数据是否有效、方向是否明确、价差是否足够，再显示观察或确认信号。
3. **记得清楚**：手工记录真实成交，区分已完成和未闭合的做 T 周期。
4. **能够复盘**：统计每个闭合周期的实际差价、费用、成本变化和成功率。

## 你可以用它做什么？

- 同时追踪多只 A 股或场内 ETF；
- 查看最新价、1 分钟 K 线、分时均价线、成交量和上证指数环境；
- 查看 B 点、S 点的“观察”和“确认”状态，而不是只给一个生硬箭头；
- 行情异常或过期时自动冻结信号，避免拿旧数据继续判断；
- 手工记录券商已经成交的真实买卖，自动更新持仓成本；
- 统计闭合做 T 周期的成功率和实际降本结果；
- 在电脑或手机浏览器中使用；
- 可选同步到 M5Stack StopWatch，或查看可转债同步雷达。

## 3 分钟开始使用

### Windows 小白用户

开始前，只需要安装 [Node.js 22 或更高版本](https://nodejs.org/)。不需要安装 Python，也不需要申请 Tushare 或行情 API Key。

1. 点击 GitHub 页面右上方绿色的 **Code** 按钮。
2. 点击 **Download ZIP**，下载后解压到一个固定文件夹。
3. 打开解压后的文件夹，双击 `start-local.cmd`。
4. 第一次运行会自动安装依赖，耐心等待命令窗口显示本地访问地址。
5. 浏览器打开 <http://localhost:4173/>。

以后再次使用，只需要双击 `start-local.cmd`。运行期间不要关闭弹出的命令窗口。

### macOS / Linux

```bash
git clone https://github.com/MitziTung-CIINC/intraday-compass.git
cd intraday-compass
chmod +x start-local.sh
./start-local.sh
```

开发者也可以手动启动：

```bash
corepack pnpm install
corepack pnpm run local
```

## 第一次打开后怎么设置？

页面会自动显示“管理监测股票”。按照下面顺序填写即可：

1. 输入证券名称，例如“贵州茅台”或“沪深 300 ETF”。
2. 输入 6 位证券代码，系统会自动识别沪市、深市或北交所。
3. 填写目前持仓股数、今日可卖数量和持仓成本。
4. 股票通常选择 **T+1**。只有已经确认支持当日回转的 ETF 才选择 **T+0**。
5. 点击“添加并追踪”。

添加后，左侧列表可以继续新增、修改或删除证券。这里填写的是本地盯盘资料，不会同步到 GitHub。

## B 点和 S 点怎么看？

- **B 点**：模型发现了偏向低吸或买回的结构。
- **S 点**：模型发现了偏向高抛或卖出的结构。
- **观察**：部分条件已经出现，但还没有全部成熟，适合继续等待。
- **确认**：数据、方向、位置、价差和时段等硬条件已经通过，但仍然只是辅助判断，不代表必须交易。
- **冻结**：行情过期、关键数据缺失或校验失败，模型暂时停止输出 B/S 判断。

模型主要观察五类信息：

```text
位置与支撑 25%
+ 指数与个股环境 20%
+ 分时均价线结构 20%
+ 5 分钟波段量能 20%
+ 1 / 5 分钟九转共振 15%
```

量能候选默认达到 55 分开始提示，普通候选默认达到 60 分开始提示；75 分以上且硬门槛全部通过，才会升级为确认。MACD 和板块信息只作辅助，不会单独决定买卖点。

## 如何记录真实操作？

“记录真实买入 / 卖出”不是模拟下单，也不会向券商发送委托。正确用法是：

1. 先在自己的券商软件中完成交易；
2. 根据成交回报，把成交方向、数量、价格和费用手工填入分时罗盘；
3. 系统按照同一证券的买卖记录匹配闭合周期；
4. 只有买卖数量已经闭合，才会计入做 T 成功率；
5. 未买回或未卖完的记录会单独显示，不会被误算成成功交易。

这样可以避免只记住“卖在高点”的一半操作，却忘记买回价格、手续费和持仓变化。

## 行情数据从哪里来？

项目自带一个只在本机运行的行情桥：

```text
http://localhost:8765/quote?symbol={symbol}&market={market}
```

默认使用无需密钥的东方财富公开行情接口：

- 快照接口：更新最新价；
- `trends2`：读取当日 1 分钟 K 线、市场指数和股票行业板块分钟线；
- `kline`：读取多日日 K 数据。

ETF 会使用自身分钟线、日 K 和对应市场指数。免费接口无法可靠识别 ETF 跟踪指数时，页面会明确显示该辅助项不可用，不会用大盘数据冒充。

需要注意：公开接口可能延迟、限流、变更或停止服务，也不是交易所直连逐笔行情。页面显示的“源站 xx ms”只是本次网络请求耗时，不等于行情相对交易所的真实延迟。数据不完整、过期或校验失败时，页面可以继续显示最新价，但会冻结 B/S 判断。

更详细的数据结构和健康检查说明见 [`docs/hybrid-market-data.md`](docs/hybrid-market-data.md)。高级用户也可以在“行情配置”中接入自己的 REST 或 WebSocket 数据源。

## 数据保存在哪里？

- 追踪证券和持仓配置保存在当前浏览器的 `localStorage`；
- 手工成交记录保存在项目目录中的本机数据库；
- 数据不会自动上传到 GitHub，也不会发送给其他测试者；
- 清理浏览器数据或删除整个项目文件夹，可能导致记录丢失。

如果要长期使用，请定期备份自己的本地记录。不要把包含真实持仓或成交记录的数据库提交到公开仓库。

## 可选：同步到 M5Stack StopWatch

刷入配套固件后，可以把最多 8 只持仓、18 根 1 分钟 K 线和当前 B/S 成熟度同步到手表：

1. 首次使用时连接手表的 `Compass-xxxx` 热点；
2. 访问 `http://192.168.4.1`，填写 2.4 GHz Wi-Fi；
3. 让电脑和手表处于同一局域网；
4. 在页面右上角“行情配置 → StopWatch 硬件同步”中填写设备地址和固件的 `DEVICE_API_KEY`；
5. 点击“检测设备”，确认成功后开启同步。

默认设备地址可尝试 `http://intraday-compass.local`，也可以使用手表屏幕显示的局域网 IP。

## 可选：转债同步雷达

启动应用后访问 <http://localhost:4173/bond-radar>，可以查看可转债与正股向上联动的候选结果。雷达会过滤成交不活跃、趋势不同步或带 ST / 退市风险标识的组合，并保留波动、活跃度、联动弹性和转换溢价率等复核字段。

![转债同步雷达预览](public/og.png)

手动更新数据：

```bash
corepack pnpm run bond:update
```

采集失败时脚本会直接报错，不会生成伪造行情。

## 常见问题

### 页面打不开怎么办？

先确认 `start-local.cmd` 的命令窗口没有关闭，再访问：

- 页面：<http://localhost:4173/>
- 行情健康检查：<http://localhost:8765/health>

如果健康检查也打不开，通常是行情桥没有启动或 8765 端口被占用。

### 为什么有价格，但没有 B/S 提示？

常见原因包括行情已经过期、分钟线不完整、快照与分钟线偏差过大、价差不足，或者信号仍处于观察阶段。页面会显示冻结或等待原因。

### 支持场内 ETF 吗？

支持查看和记录，但是否允许 T+0 取决于具体 ETF。请以券商交易规则和基金法律文件为准，不要只凭证券代码判断。

### 会自动帮我买卖吗？

不会。项目没有券商登录、资金读取或自动下单功能。

## 重要风险说明

- 本项目不连接券商，不读取资金，不发送交易委托；
- B/S 信号和成熟度只是研究辅助，不构成投资建议；
- 做 T 可能出现卖飞、补仓后继续下跌、无法当日闭合和费用超过价差等风险；
- 做 T 成功率只统计已经闭合的买卖周期，并扣除手工录入的费用；
- 场内 ETF 的回转规则必须由用户自行确认；
- 免费公开行情没有交易所授权实时等级或持续可用性保证；
- 实盘操作请始终以券商终端显示的数据和交易规则为准。
